Can Recommender Systems Teach Themselves?

A recursive self-improving framework with fidelity control for sparse sequential recommendation.

Luankang Zhang, Hao Wang, Zhongzhou Liu, Mingjia Yin, Yonghao Huang, Jiaqi Li, Wei Guo, Yong Liu, Huifeng Guo, Defu Lian, Enhong Chen

Paper arXiv Code BibTeX

Recursive Self-Improvement Without External Teachers

RSIR turns a recommender into its own data generator. The generated data is not accepted blindly: a fidelity check keeps the loop close to plausible user preference trajectories.

1. Train

Train a recommender on the current dataset using next-item prediction.

2. Generate

Use the trained model to create synthetic user interaction sequences.

3. Filter

Accept generated steps only when they pass the fidelity-based rank check.

4. Retrain

Merge valid synthetic sequences with the training set and train a successor model.

Key Findings

The paper reports that RSIR improves performance across datasets, iterations, and backbone models while avoiding the collapse observed when fidelity control is removed.

+8.02%
Single-iteration gain

On Amazon-Sport, the paper reports an 8.02% Recall@10 gain for HSTU after one RSIR iteration.

+13.92%
Cumulative improvement

The same setting reaches a 13.92% Recall@10 gain after three recursive iterations.

w/o vs. w
Fidelity matters

Ablations show that uncontrolled generation can pollute the loop, while fidelity control stabilizes self-improvement.

Code

The repository exposes two modes: `recommendation` for model training and evaluation, and `generation` for RSIR augmented data creation.

Train on original data 
python run.py -m SASRec -d amazon-toys --trainfile "" --mode recommendation --device 0
Generate a paper-style iteration file 
python run.py -m SASRec -d amazon-toys --trainfile "" --mode generation \
  --theta_r_path saved/SASRec/amazon-toys/<checkpoint>.ckpt \
  --output_trainfile "_1th" --device 0
